# QUICK REFERENCE CARD

## 🚀 FASTEST WAY: 2 MINUTES

### Phone: Install Expo Go
```
Play Store → "Expo Go" → Install
```

### Mac: Start Dev Server
```bash
npm start
# (in CreatorFormatLite folder)
```

### Phone: Scan & Run
```
Expo Go → "Scan QR code" → Point at Mac → Wait 30 sec → RUN!
```

---

## 📋 COMMANDS YOU MIGHT NEED


## ✅ REQUIREMENTS

---

## 🆘 TROUBLESHOOTING

**App won't load?**
- Check same WiFi
- Run `npm start` again
- Rescan QR code

**Permission errors?**
- Settings > Apps > Permissions > Allow

**Crashes?**
- Terminal: Press 'r'
- Phone: Force close, rescan
